# AI Recruitment Automation Platform

Automation platform for candidate screening, workflow orchestration and hiring process optimization.

## Overview
This project focuses on automating recruitment operations using AI-assisted workflows to improve speed, accuracy and scalability.

## Core Features
- Candidate intake automation  
- Resume screening workflows  
- Interview pipeline orchestration  
- Automated candidate routing  
- Recruitment reporting and analytics  

## Architecture
### Stack
- Python
- Flask
- PostgreSQL
- APIs & Integrations
- AI-driven Automation

## Workflow
```text
Candidate Intake
↓
Screening Engine
↓
Interview Routing
↓
Client Submission
↓
Analytics
```
